# Gestor de Gastos Personales

Aplicación de consola desarrollada en Python para registrar, visualizar y filtrar gastos personales de manera sencilla.

## Características

- **Agregar gastos:** Registra nuevos movimientos especificando descripción, monto y categoría.
- **Listar gastos:** Muestra todos los gastos almacenados durante la sesión actual.
- **Filtrar por categoría:** Permite buscar y visualizar únicamente los gastos que pertenecen a una categoría específica.
- **Interfaz interactiva:** Menú continuo en terminal hasta que el usuario decida salir.

## Requisitos

- **Python 3.x** (no requiere librerías externas; utiliza únicamente funciones nativas de Python).

## Instalación y ejecución

1. Guarda el código en un archivo llamado `Gestor de Gastos Personales.py`.
2. Abre una terminal o consola de comandos en la carpeta donde guardaste el archivo.
3. Ejecuta el programa con el siguiente comando:

```bash
python Gestor de Gastos Personales.py
